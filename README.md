🚀 SQLx Checker 2.0 🚀
Автор: kreedzru
Версия: 2.0

🌟 Что такое SQLx Checker 2.0?:
- SQLx Checker 2.0 — это мощный , гибкий и легко настраиваемый плагин для работы с базами данных. Он позволяет управлять подключениями, выполнять SQL-запросы (синхронно или асинхронно), собирать статистику их выполнения и логировать все важные события. Этот инструмент идеально подходит как для небольших проектов, так и для масштабируемых систем.

🔧 Основные возможности:

🖥️ Подключение к базам данных:
- Автоматическое подключение через конфигурационный файл (sqlx_checkers.cfg).
- Проверка успешности подключения и логирование результатов.
- Возможность включения/выключения использования баз данных через параметр db_enabled.
  
💡 Примечание: 
- Все подключения проверяются на корректность, и вы всегда будете знать, если что-то пошло не так! 

📊 Сбор статистики выполнения запросов:
- Сбор общего количества выполненных запросов (g_TotalQueries) и общего времени их выполнения (g_TotalTime).
- Логирование статистики каждые stats_interval секунд (настраивается в конфигурации).
- Вычисление среднего времени выполнения запросов и вывод их в логи консоли.
  
📈 Почему это важно?:
- Вы сможете отслеживать производительность ваших запросов и оптимизировать их, чтобы ваше приложение работало быстрее! 

⚙️ Управление конфигурацией:
- Загрузка параметров подключений и настроек плагина из конфигурационного файла.
- Включение/выключение сбора статистики через параметр SQLxStatsOnOff.
  
🛠️ Настройте всё под себя!:
- Конфигурация позволяет адаптировать плагин под любые нужды вашего проекта. 

📝 Логирование событий:
- Информационные сообщения (например, успешные подключения к базе данных).
- Логирование ошибок (например, сбои подключений).
  
🔍 Никаких скрытых проблем!: 
- Все события фиксируются, чтобы вы могли легко диагностировать проблемы. 

🛠️ API Include (sqlx_api.inc):
- API предоставляет удобный интерфейс для разработчиков, чтобы они могли использовать функциональность плагина SQLx Checkers в своих проектах. Основной функционал API включает:

🖥️ Подключение к базе данных:
- SQLx_Init: Инициализирует подключение к базе данных.
- SQLx_IsConnected: Проверяет состояние подключения.
- SQLx_Disconnect: Закрывает соединение с базой данных.
  
🔄 Выполнение запросов:
- SQLx_Query: Выполняет синхронный SQL-запрос.
- SQLx_QueryAsync: Выполняет асинхронный SQL-запрос.
- SQLx_GetAsyncResult: Получает результат асинхронного запроса.
  
🌐 Асинхронные запросы?:
- Да! Ваш проект/плагин не будет блокироваться во время выполнения сложных запросов. 

📊 Управление статистикой:
- SQLx_GetTotalQueries: Возвращает общее количество выполненных запросов.
- SQLx_GetAverageQueryTime: Возвращает среднее время выполнения запросов.
- SQLx_ResetStats: Сбрасывает счетчики статистики.

📉 Статистика — ключ к успеху!:
- Следите за производительностью и оптимизируйте свои запросы. 

📝 Логирование:
- SQLx_LogInfo: Логирует информационные сообщения.
- SQLx_LogError: Логирует ошибки.
  
📋 Логи — ваши лучшие друзья!: 
- Они помогут вам быстро находить и исправлять ошибки. 

⚙️ Работа с конфигурацией:
- SQLx_LoadConfig: Загружает конфигурацию из файла.
- SQLx_GetConfigValue: Получает значение параметра из конфигурации.
  
🗂️ Гибкость на максимум!: 
- Настройте плагин под свои нужды с помощью конфигурационного файла. 

📦 Установка и настройка:
- Скопируйте файлы плагина в соответствующие директории вашего проекта.
- Настройте параметры подключения к базе данных в файле sqlx_checkers.cfg.
- Используйте API для интеграции функциональности в ваш проект.
  
📂 Всё просто!:
- Следуйте инструкциям, и вы быстро запустите плагин.
